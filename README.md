# 霖霖的課程預約系統 (Course Booking Web App)

> 原生 AppSheet 轉移至 **GitHub Pages + Google Sheets** 的零成本高彈性解決方案。  
> 具備簡潔流暢的手機端預約介面，以及**全功能管理後台 (`admin.html`)**，管理者不需要頻繁開啟試算表，直接在網頁表單填寫即可完成開課、改期、調名額與現場簽到！

---

## 📱 系統畫面與結構

```
GitHub Repository
├── index.html                  # 學員端：線上預約報名首頁（AppSheet 卡片風格，手機優先自適應）
├── admin.html                  # 管理端：視覺化後台（開課表單、學員簽到、名額統計、公告設定）
├── GoogleAppsScript_Code.js    # 後端核心：Google Apps Script 串接腳本（全自動建表、CORS API）
└── README.md                   # 系統使用與部署指南
```

---

## 🌟 主要功能與特色

### 1. 學員端 (`index.html`)
- **AppSheet 卡片式介面 (Deck View)**：清晰展示課程名稱、授課教練、日期時段、地點教室。
- **日期標籤快速切換**：自動依據課程日期產生橫向滾動頁籤。
- **即時名額條與防呆**：顯示「剩餘 X 名」或「已額滿（自動鎖定防超額）」。
- **一鍵登記預約**：填寫姓名、電話、Line ID、備註即可完成，自動記住聯絡資訊，下次免重填。
- **電子預約憑證**：送出後即時彈出預約編號與時段確認卡片。

### 2. 管理端 (`admin.html`)
- **全面視覺化維護，告別手動切換試算表**：
  - **開立新課程**：彈出表單填寫名稱、教練、人數上限、日期、開始/結束時間、地點、狀態、備註，送出即自動同步至 Google Sheets。
  - **一鍵編輯/刪除**：現有課程可隨時修改時段與名額，或直接刪除。
  - **學員出席簽到**：預約名冊列表顯示姓名、電話、報名時間，支援一鍵點擊「簽到」、「取消名額」或「還原」。
  - **即時搜尋與過濾**：快速以姓名、電話、課程關鍵字檢索。
  - **儀表板即時指標**：即時統計開課數、預約人次、額滿時段、簽到率。
  - **公告與全域設定**：可直接於網頁設定前台提醒文字與後台通關密碼。

## 🚀 完整部署與啟用指南 (三步驟)

### 步驟一：準備 Google Sheets 資料庫與 API 部署 (約 2 分鐘)

1. 前往 [Google 雲端硬碟](https://drive.google.com/)，建立一份新的 Google 試算表（例如命名為：`霖霖課程預約資料庫`）。
2. 點擊頂部選單的 **「擴充功能」 ➔ 「Apps Script」**。
3. 清空原有的 `Code.gs`，將本專案中的 [`GoogleAppsScript_Code.js`](./GoogleAppsScript_Code.js) 內容**全部複製貼上**，按儲存 (Ctrl+S)。
4. 在編輯器上方執行函式下拉選單中選擇 **`setupSheets`**，點擊 **「執行」**：
   - 首次執行會彈出授權視窗，點擊「審查權限」➔ 選擇您的 Google 帳戶 ➔ 點「進階」➔ 點「前往... (不安全)」➔ 點「允許」。
   - 執行成功後，回到 Google 試算表，會看到系統已自動建立《**課程清單**》、《**預約記錄**》、《**系統設定**》三張標準表格與示範資料！
5. 點擊編輯器右上角 **「部署」 ➔ 「新建部署」**：
   - 點擊左側齒輪，選擇 **「網路應用程式」 (Web App)**。
   - 說明：`課程預約 API`。
   - 執行身分：`我`。
   - **誰可以存取：`任何人` (Anyone)** *(重要：讓學員無需登入 Google 即可載入與送出報名)*。
6. 點擊部署，複製最後顯示的 **「網路應用程式網址」 (Web App URL)**（格式如：`https://script.google.com/macros/s/AKfycb.../exec`）。

---

### 步驟二：推送到 GitHub 並開啟 GitHub Pages 免費上線 (約 1 分鐘)

1. 在 GitHub 上建立一個新的公開儲存庫（Repository），例如命名為 `course-booking`。
2. 將本地專案推送至 GitHub（終端機指令）：
   ```bash
   git remote add origin https://github.com/<您的GitHub帳號>/course-booking.git
   git push -u origin main
   ```
3. 進入 GitHub Repository 的 **Settings ➔ Pages**：
   - **Source** 選擇 `Deploy from a branch`。
   - **Branch** 選擇 `main`，資料夾選擇 `/(root)`。
   - 點擊 **Save**。
4. 稍等約 30 秒至 1 分鐘，GitHub 會顯示您的專屬上線網址：
   - **學員預約端**：`https://<您的GitHub帳號>.github.io/course-booking/`
   - **管理者後台**：`https://<您的GitHub帳號>.github.io/course-booking/admin.html`

---

### 步驟三：首次設定 API 網址 (僅需 10 秒)

1. 打開管理者後台網址：`.../admin.html`。
2. 點擊右上角 **「連接 API」** 按鈕。
3. 貼上步驟一所取得的 **Google Apps Script 網路應用程式網址**，密碼確認為 `admin888`，點擊儲存。
4. 網頁會立即載入 Google Sheets 上的所有課程與預約名單，後續新增修改將完全自動雙向同步！

## 💡 日常維護指引

| 任務情境 | 操作方式 |
| :--- | :--- |
| **開立新的課程時段** | 進入 `admin.html`，點擊「開立新課程時段」，填妥時間名額後送出，前台與 Sheet 同步更新。 |
| **課程改期或修改名額** | 進入 `admin.html` 的課程管理頁籤，點擊該課程右側的「編輯」，修改後儲存即可。 |
| **現場學員出席簽到** | 進入 `admin.html` 的「學員預約名單」，找到該學員點擊綠色「簽到」按鈕即可完成核銷。 |
| **學員取消或改期** | 於名單中點擊「取消」，名額會即時釋回前台讓其他學員預約。 |
| **修改預約公告須知** | 於後台切換至「系統與公告設定」，修改公告文字後儲存。 |

## 🔒 隱私與安全性
- 管理者密碼預設為 `admin888`，可於後台「系統與公告設定」自訂修改。
- 本架構無第三方伺服器參與，資料完全保存在您專屬的 Google 雲端試算表中，隱私安全無虞。
