# 霖霖的課程預約系統 (Course Booking Web App)

> 從 AppSheet 轉移至 **GitHub Pages + Google Sheets** 的零成本高彈性解決方案。  
> 具備簡潔流暢的手機端預約介面，以及**全功能管理後台 (`admin.html`)**，  
> 管理者不需要頻繁開啟試算表，直接在網頁表單填寫即可完成開課、改期、調名額、現場簽到與完整報表統計！

---

## 📱 系統畫面與結構

```
GitHub Repository
├── index.html                  # 學員端：線上預約報名首頁（手機優先自適應）
├── admin.html                  # 管理端：視覺化後台（開課、收款確認、簽到、過往統計、系統設定）
├── manual.html                 # 使用說明手冊（互動式 HTML，含畫面模擬）
├── GoogleAppsScript_Code.js    # 後端核心：Google Apps Script 串接腳本（全自動建表、CORS API）
├── tailwind.css                # 前端樣式（本地 Tailwind CSS）
└── README.md                   # 系統使用與部署指南
```

## 🌟 主要功能與特色

### 1. 學員端 (`index.html`)

- **卡片式課程列表**：清晰展示課程名稱、日期時段、地點、剩餘名額。
- **早鳥 / 定價自動切換**：超過早鳥截止日（台灣時間 23:59）自動切換為定價顯示，無需手動修改。
- **即時名額與防超額**：顯示「剩餘 X 名」或「已額滿（自動鎖定）」。
- **一鍵登記預約**：填寫姓名、電話、Line ID、Email、備註即可完成，自動記住聯絡資訊，下次免重填。
- **電子預約憑證**：送出後即時彈出預約編號、時段確認、匯款帳號資訊。
- **前台公告顯示**：管理者設定的公告與注意事項即時呈現在報名頁頂部。

---

### 2. 管理端 (`admin.html`) — v3.6.8

#### 🔐 安全登入
- 密碼驗證直接對照 Google 試算表，不依賴 localStorage 儲存明文密碼。
- 支援 Session 保持，重新整理不需重新登入。

#### 📅 課程維護
- **開立新課程**：填寫名稱、人數上限、日期、開始/結束時間、教室地點、早鳥價、定價、早鳥截止日、課程說明，送出即自動同步至 Google Sheets。
- **虛擬報名數**：可設定前台顯示的虛擬人數，讓課程看起來更熱門（實際名額不受影響）。
- **一鍵編輯 / 刪除**：現有課程可隨時修改；刪除時若有有效預約，系統會提示並要求二次確認。
- **課程搜尋與排序**：可依「開課時間」或「報名人數（多→少）」排列，支援即時搜尋。
- **自動標示已結束課程**：過期課程自動顯示「已結束」樣式，並歸入過往統計區。

#### 📋 預約名冊
- **完整學員資訊**：姓名、電話、Line ID、Email、匯款末五碼、繳費金額、備註需求、管理備註（僅後台可見）。
- **狀態流程管理**：
  ```
  ⏳ 待確認 → ✅ 報名成功 → 🎯 已簽到 → 🏁 已完成
                                   ↓
                              ❌ 已取消（可還原 / 永久刪除）
  ```
- **確認入帳**：一鍵更新為「報名成功」，可選擇同時寄送確認信給學員。
- **現場簽到**：點擊即更新為「已簽到」，支援取消簽到還原。
- **LINE 快捷通知**：自動複製通知訊息並跳轉至學員 LINE，快速完成通知。
- **搜尋與篩選**：支援姓名、電話、課程關鍵字搜尋，可依預約狀態篩選，支援依開課時間或報名時間排序。
- **修改預約資料**：可修改所有欄位，包含更換所屬課程、調整金額、補填 Email、新增管理備註。

#### 📊 過往統計
課程結束後預約記錄自動歸入，提供兩種檢視：

**過往明細**
- 全部歷史報名記錄（含已取消），可搜尋、排序、繼續操作。

**學員統計**
- 以學員為單位統計歷史報名次數。
- 🥇🥈🥉 排行榜顯示，自動標示「回流學員」（≥2次）及「★ 核心忠實」（≥3次）。
- 三大關鍵指標：獨立學員數、累積人次（不含取消）、回流學員數。

#### ⚙️ 系統設定
- **基本設定**：系統前台名稱、前台公告、常用教室選單、早鳥截止預設天數。
- **收款帳號**：銀行代碼與名稱、收款帳號、戶名，自動顯示在學員報名完成頁面。
- **管理密碼修改**：留空不變更，輸入新密碼即更新。
- **Google 試算表連線**：一鍵測試連線狀態，顯示目前串接的 GAS 網址。
- **QR Code 同步**：產生管理後台或學員報名頁的專屬 QR Code，新裝置掃描即可使用。
- **Telegram Bot 推播**：設定 Bot Token 與 Chat ID，有學員報名時即時通知。
- **Email 通知**：設定管理員收件信箱、寄件者名稱，支援學員確認信（入帳時可選擇是否寄送）。

#### 🛠️ 介面功能
- **字體大小調整**：右上角可即時縮放，設定自動記憶。
- **連線狀態燈號**：即時顯示 Google 試算表連線狀態（綠色閃爍 / 紅色失敗 / 灰色連線中）。
- **版本更新提示**：有新版本時頂部自動顯示更新橫幅。
- **手機 RWD 完整支援**：所有頁籤、名冊、設定均有手機版 Card 布局。

## 🚀 完整部署與啟用指南（三步驟）

### 步驟一：準備 Google Sheets 資料庫與 API 部署（約 2 分鐘）

1. 前往 [Google 雲端硬碟](https://drive.google.com/)，建立一份新的 Google 試算表（例如命名為：`霖霖課程預約資料庫`）。
2. 點擊頂部選單 **「擴充功能」→「Apps Script」**。
3. 清空原有的 `Code.gs`，將本專案中的 [`GoogleAppsScript_Code.js`](./GoogleAppsScript_Code.js) 內容**全部複製貼上**，按儲存（Ctrl+S）。
4. 在編輯器上方執行函式下拉選單中選擇 **`setupSheets`**，點擊「執行」：
   - 首次執行會彈出授權視窗：點「審查權限」→ 選擇您的 Google 帳戶 → 點「進階」→ 點「前往...(不安全)」→ 點「允許」。
   - 執行成功後，回到 Google 試算表，系統會自動建立《課程清單》、《預約記錄》、《系統設定》三張表格與示範資料。
5. 點擊編輯器右上角 **「部署」→「新建部署」**：
   - 點擊左側齒輪，選擇「網路應用程式 (Web App)」。
   - 說明：`課程預約 API`
   - 執行身分：`我`
   - **誰可以存取：`任何人 (Anyone)`**（重要：讓學員無需登入 Google 即可報名）
6. 點擊部署，複製顯示的 **「網路應用程式網址 (Web App URL)」**
   （格式如：`https://script.google.com/macros/s/AKfycb.../exec`）

> ⚠️ **注意**：每次修改 `GoogleAppsScript_Code.js` 後，需重新「部署」→「管理部署」→「編輯」→ 版本選「新版本」→ 儲存，才能生效。

---

### 步驟二：推送到 GitHub 並開啟 GitHub Pages（約 1 分鐘）

1. 在 GitHub 建立一個新的公開儲存庫，例如命名為 `course-booking`。
2. 將本地專案推送至 GitHub：
   ```bash
   git remote add origin https://github.com/<您的GitHub帳號>/course-booking.git
   git push -u origin main
   ```
3. 進入 GitHub Repository 的 **Settings → Pages**：
   - Source 選擇 `Deploy from a branch`
   - Branch 選擇 `main`，資料夾選擇 `/(root)`
   - 點擊 Save
4. 稍等約 30 秒，GitHub 會顯示您的專屬網址：
   - **學員預約端**：`https://<您的GitHub帳號>.github.io/course-booking/`
   - **管理者後台**：`https://<您的GitHub帳號>.github.io/course-booking/admin.html`
   - **使用說明手冊**：`https://<您的GitHub帳號>.github.io/course-booking/manual.html`

---

### 步驟三：首次登入並完成設定（約 5 分鐘）

1. 開啟管理者後台網址：`.../admin.html`
2. 輸入管理密碼（預設請洽系統建置人員）並登入
3. 切換至 **「系統設定」** 頁籤，完成以下設定：

| 設定項目 | 說明 |
| :--- | :--- |
| 系統前台名稱 | 顯示在學員報名頁頂部的標題 |
| 收款帳號（銀行、帳號、戶名） | 學員報名完成後看到的匯款資訊 |
| 管理密碼 | 建議立即修改預設密碼 |
| 常用教室選單 | 每行一個地點，開新課程時可快速選取 |
| 早鳥截止預設天數 | 開新課程時自動計算早鳥截止日（預設 7 天） |
| Telegram / Email 通知 | 設定後有學員報名即時通知 |
| 測試連線 | 確認 Google 試算表正常串接 |

4. 填寫完成後點 **「儲存所有設定」**，確認顯示成功提示。
5. 切換至 **「課程維護」** 頁籤，點 **「開立新課程時段」** 建立第一個課程。
6. 分享學員端網址，開始接受報名！

## 💡 日常維護指引

| 任務情境 | 操作方式 |
| :--- | :--- |
| **開立新的課程時段** | 進入「課程維護」頁籤 → 點「開立新課程時段」→ 填妥資料後送出，前台與 Sheets 同步更新 |
| **課程改期或修改名額** | 課程維護頁籤 → 點該課程右側「編輯」→ 修改後儲存 |
| **設定早鳥優惠** | 編輯課程時填入早鳥價、定價、早鳥截止日，系統自動於截止後切換為定價 |
| **確認學員匯款** | 預約名冊 → 找到該學員 → 點「確認入帳」→ 狀態更新為「報名成功」 |
| **現場學員出席簽到** | 預約名冊 → 找到該學員 → 點「現場簽到」→ 更新為「已簽到」 |
| **學員取消報名** | 名冊中點「取消」，名額即時釋回前台（資料保留，可還原） |
| **聯繫學員（LINE）** | 名冊中點 LINE 圖示 → 自動複製通知訊息並跳轉至學員 LINE |
| **查看歷史學員** | 切換至「過往統計」→「學員統計」子模式，查看排行榜與回流數據 |
| **修改公告或通知設定** | 切換至「系統設定」頁籤，修改後點「儲存所有設定」 |
| **在新手機使用後台** | 系統設定中點「顯示 QR Code」或「複製管理後台網址」，掃描或開啟後輸入密碼即可 |

## 🔒 隱私與安全性

- 管理密碼直接對照 Google 試算表驗證，不以明文儲存在瀏覽器本地。
- 本架構**無第三方伺服器參與**，所有課程與報名資料完全保存在您專屬的 Google 試算表中。
- 建議定期至 Google 試算表下載 Excel 備份，以防萬一。
- 管理後台網址包含 `admin.html`，建議不要公開分享，僅限管理者使用。

## ❓ 常見問題

**Q：學員報名後我沒收到通知？**  
A：請至「系統設定」確認 Telegram Bot Token / Chat ID 或 Email 設定正確，並點「測試」按鈕確認可以正常收到。

**Q：連線狀態顯示紅色失敗？**  
A：請確認網路正常，並至「系統設定」點「測試連線」。若持續失敗，請確認 GAS 是否重新部署（每次修改 Code.gs 都需要重新部署新版本）。

**Q：修改了 Apps Script 但沒有生效？**  
A：每次修改 Code.gs 後，必須「部署」→「管理部署」→「編輯」→ 版本選「新版本」→ 儲存，才能讓最新程式碼生效。

**Q：課程時間到了但還在「預約名冊」沒有移到「過往統計」？**  
A：系統依據課程結束時間（台灣時間）自動判斷，請確認課程的結束時間設定正確。若課程沒有設定結束時間，系統會以當天 23:59 作為判斷基準。

**Q：可以在手機上使用管理後台嗎？**  
A：可以。管理後台完整支援手機 RWD 版面，也可透過「系統設定」中的 QR Code 功能快速在新手機開啟。
